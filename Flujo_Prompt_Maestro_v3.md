# RELAÇÕES CRÍTICAS QUE O FLUXO DEVE PRESERVAR

### 1. PGR não nasce de uma auditoria

```text
Contexto
   ↓
GRO
   ↓
Identificação de perigos
   ↓
Avaliação de riscos
   ↓
Inventário de riscos
   ↓
PGR
```

A auditoria pode **verificar** elementos do PGR, mas não é sua origem obrigatória.

---

### 2. PCMSO não é simplesmente uma etapa posterior ao PGR

```text
Riscos e condições de trabalho ──────┐
                                     ├──► PCMSO
Informações médicas ocupacionais ────┘
```

Existe integração entre os domínios, mas eles permanecem distintos.

---

### 3. PPP não deve ser representado como simples consequência automática do S-2240

```text
Condições de trabalho
       │
       ├──► Avaliações / caracterizações
       │
       ├──► Documentação técnica
       │       └──► LTCAT, quando aplicável
       │
       ├──► Informações laborais/previdenciárias
       │
       └──► Sistemas governamentais
               └──► S-2240, quando aplicável

                    ↓

                   PPP
```

O SaaS deve preservar as relações entre esses elementos sem impor uma causalidade universal.

---

### 4. CAT e S-2210 pertencem ao domínio de ocorrências

```text
Acidente / ocorrência
        │
        ├──► Investigação
        ├──► Tratamento
        ├──► Evidências
        ├──► Ações
        │
        └──► CAT / S-2210
                quando aplicável
```

---

### 5. ASO, exames e S-2220 pertencem ao domínio de saúde ocupacional

```text
PCMSO
  │
  ├──► Planejamento médico
  ├──► Exames
  ├──► Avaliações clínicas
  ├──► ASO
  │
  └──► S-2220
          quando aplicável
```

---

### 6. S-2240 pertence ao domínio governamental, não ao domínio documental

```text
Condições ambientais
        │
        ├──► Avaliação / caracterização
        │
        ├──► Registros técnicos
        │
        ├──► Histórico laboral
        │
        └──► S-2240
                │
                ▼
          Sistema governamental
```

**PPP, LTCAT, PGR, PCMSO, ASO, CAT, S-2210, S-2220 e S-2240 permanecem entidades/domínios distintos, conectados quando houver fundamento normativo para essa conexão.**
