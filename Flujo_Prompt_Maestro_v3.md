## Lectura conceptual

El flujo principal es:

**Contexto**
→ **Aplicabilidad**
→ **Obligaciones**
→ **Responsabilidades**
→ **Procesos/Controles**
→ **Ejecución**
→ **Resultados**
→ **Cumplimiento / Hallazgos / Necesidades**
→ **Acciones**
→ **Evidencias**
→ **Validación**
→ **Artefactos**
→ **Gobierno cuando corresponda**
→ **Histórico**
→ **Seguimiento**
→ **Nuevos eventos/revisiones**

### Dominios transversales

**GRO/PGR**, **PCMSO**, **medicina ocupacional**, **riesgos**, **equipos**, **EPI**, **capacitación**, **accidentes**, **documentos**, **eSocial** y demás dominios **no son etapas obligatoriamente secuenciales**.

Son componentes conectados al ciclo mediante obligaciones y relaciones.

Por ejemplo:

```text
OBLIGACIÓN
    │
    ├──► PROCESO / CONTROL
    │
    ├──► EVALUACIÓN
    │
    ├──► DOCUMENTO
    │
    ├──► CAPACITACIÓN
    │
    ├──► EQUIPO
    │
    ├──► EPI
    │
    ├──► RIESGO
    │
    ├──► MEDICINA
    │
    ├──► ACCIÓN
    │
    └──► GOBIERNO / eSocial
```

Por eso, el sistema no debe tener una única "ruta SST".

Debe tener un **grafo de obligaciones, procesos, personas, activos, resultados, evidencias y artefactos**, con diferentes workflows según el tipo de obligación.
